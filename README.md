# Dela_Torre-Study_Planner

A simple full-stack web application designed to help students organize, schedule, and track their study sessions.

Overview:
Study Planner allows users to create and manage study plans in one place. Users can schedule study sessions, set priorities, track progress, use a study timer, and view their plans through a calendar.
This project was created as a full-stack application using React, Node.js, Express, and PostgreSQL.

Features:
- Create study plans
- Edit existing study plans
- Delete study plans
- View study plans in a calendar
- Start and manage study sessions with a timer
- Pause and resume study sessions
- Mark study sessions as completed
- Undo completed sessions
- Search study plans
- Filter plans by priority and status
- View study statistics and progress
- Track study streaks
- Light and dark mode
- Responsive user interface
